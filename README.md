# NoteHub

A personal note management application built with **Next.js, React, and TypeScript**.

The project was originally developed as part of my **GoIT Full Stack Developer course** and later refined and prepared as a portfolio project.

## Live Demo

[NoteHub](https://09-auth-seven-rouge.vercel.app/)

Use the **Demo Account** button on the sign-in page for quick access.

## Features

- Authentication and protected routes
- Personal notes management
- Create and delete notes
- Search and filtering
- Pagination
- Note details
- User profile and profile editing
- Session management
- Responsive UI

## Tech Stack

- Next.js
- React
- TypeScript
- TanStack React Query
- Zustand
- Axios
- CSS Modules
- REST API
- Git / GitHub
- Vercel

## Key Technical Highlights

- Next.js App Router
- Server and Client Components
- Server-side data fetching
- React Query prefetching and hydration
- Access and refresh token authentication
- HTTP cookies
- Protected routes with Next.js Proxy
- Separate client and server API layers

## Getting Started

```bash
npm install
npm run dev
```

Create `.env.local` with your API URL:

```env
NEXT_PUBLIC_API_URL=your_api_url
```

Then open `http://localhost:3000`.
